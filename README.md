# CSI-hackathon-builder-
CSI Hackathon Builder is a web-based platform designed to simplify the organization and management of college hackathons. It provides participants with an easy way to explore hackathon details, choose events, register their teams, and access important information in one place.

# CSI Hackathon Builder

A responsive web platform for discovering and managing college hackathons.

## Features

- Explore hackathons
- Search and filter hackathons
- View hackathon details
- View project details
- Hackathon registration
- Organizer management
- Registration fee information
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap
